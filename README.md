# 🚀 VSD Internship Screening – RTL Design & Synthesis

## 📌 Overview
This repository contains RTL design implementations using Verilog along with simulation and synthesis.

## 🛠️ Tools Used

- Icarus Verilog

## 📂 Structure

- docs/ → explanations
- src/ → Verilog code (to be added)
